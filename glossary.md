# `q9chat` glossary

Use these terms consistently in code, schemas, routes, tests and product copy.

| Term          | Definition                                                                                |
| ------------- | ----------------------------------------------------------------------------------------- |
| Product       | The application and domain owned by this repository.                                      |
| Scaffold      | The starting project generated by `create-q9stack`; the product owns it after generation. |
| Overlay       | Variant files copied over the base template by the generator.                             |
| Gate          | The `q9gate` run that plans and executes configured quality checks.                       |
| Lane          | One independently reported check in a gate run.                                           |
| Tracker       | `tracker.yaml`, the source of project outcomes, state and remaining work.                 |
| `unknown`     | The required proof or scope is not yet known.                                             |
| `planned`     | Work has been identified but has not started.                                             |
| `in_progress` | Work is underway but its outcome is not yet complete.                                     |
| `blocked`     | Work cannot proceed until a named dependency or decision changes.                         |
| `working`     | The stated outcome is implemented and has no remaining work.                              |
| Product theme | The product slug applied through the UI `data-theme` attribute.                           |
