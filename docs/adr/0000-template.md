# ADR 0000: Template record

- Status: accepted
- Date: `2026`

## Context

Generated projects need a short, durable record for decisions that affect the
base scaffold. Product-specific decisions belong in later ADRs.

## Decision

Use this ADR structure: status, context, decision, and consequences. Keep one
decision per ADR and link the relevant code or runbook.

## Consequences

Future changes can explain a deliberate divergence without turning the README
into a history log.
